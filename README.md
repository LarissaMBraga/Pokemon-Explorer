# PokéVerse — Pokémon Explorer

A modern, interactive Pokémon explorer built with React, TypeScript, and the PokéAPI. Discover Pokémon, explore their details, filter by type, and save your favorite discoveries in a responsive interface with smooth animations and a dark visual theme.

## Features

- **Pokédex catalog:** Browse Pokémon with pagination.
- **Live search:** Find Pokémon by name with debounced search.
- **Type filtering:** Filter the catalog by Pokémon type.
- **Favorites:** Save your favorite Pokémon, with preferences persisted in local storage.
- **Detailed Pokémon modal:** Explore additional information about selected Pokémon.
- **Featured Pokémon:** Discover a daily featured Pokémon.
- **Loading and error states:** Clear feedback while data is loading or when a request fails.
- **Responsive design:** Interface adapted for desktop and mobile screens.
- **Animated interface:** Smooth transitions and visual effects for a polished experience.

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/LarissaMBraga/Pokemon-Explorer.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Pokemon-Explorer
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Available Scripts
